## Non-Functional Requirements Matrix

| Requirement ID | Category | Metric / Target | Description |
| :--- | :--- | :--- | :--- |
| **NFR-01** | Performance | Latency < 2.0s | System pages shall load within 2 seconds under peak concurrent user requests. |
| **NFR-02** | Security | AES-256 Encryption | All user passwords and customer contact details shall be encrypted at rest. |
| **NFR-03** | Availability | 99.9% Uptime | System operations shall maintain high availability during standard workshop business hours. |
| **NFR-04** | Usability | Mobile Responsive | Customer booking interface shall render seamlessly across desktop and mobile browsers. |
